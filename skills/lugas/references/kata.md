# Daftar kata: dari bahasa kantor ke bahasa sehari-hari

Daftar ini contoh, bukan aturan mati. Kalau konteksnya memang teknis atau hukum dan istilah formalnya wajib, pakai istilah itu lalu jelaskan.

## Kata kerja yang dibungkus kata benda

| Hindari | Pakai |
|---|---|
| melakukan pendaftaran | daftar, mendaftar |
| melakukan pembayaran | bayar, membayar |
| melakukan pengecekan / pemeriksaan | cek, periksa |
| melakukan perubahan | ubah, mengubah |
| melakukan penghapusan | hapus |
| memberikan persetujuan | setuju, menyetujui |
| mengajukan permohonan | minta, mengajukan |
| proses pengunggahan sedang berlangsung | sedang mengunggah |
| telah dilakukan penyimpanan | sudah tersimpan |

## Frasa birokratis

| Hindari | Pakai |
|---|---|
| dalam rangka | untuk, supaya |
| sehubungan dengan hal tersebut | karena itu |
| adapun / perlu diketahui bahwa | (hapus, langsung ke isinya) |
| dengan ini kami sampaikan bahwa | (hapus, langsung ke isinya) |
| apabila | kalau, jika |
| sebagaimana dimaksud | seperti disebut di (sebut bagiannya) |
| guna | untuk |
| pada saat ini | sekarang |
| di kemudian hari | nanti |
| terhitung sejak tanggal | mulai |
| demikian disampaikan, atas perhatiannya diucapkan terima kasih | Terima kasih. |
| mohon kiranya | mohon, tolong |

## Kata serapan dan istilah gaya presentasi

| Hindari | Pakai |
|---|---|
| mengimplementasikan | menerapkan, menjalankan |
| mengakomodasi | menampung, memenuhi |
| optimalisasi | perbaikan, membuat lebih baik |
| sosialisasi (dalam arti memberi tahu) | memberi tahu, menjelaskan |
| stakeholder / pemangku kepentingan | pihak terkait (sebut siapa: pengurus, donatur) |
| follow up | tindak lanjut, kabari lagi |
| deadline | batas waktu, tenggat |
| update | kabar terbaru, perbarui |
| meeting | rapat |
| reminder | pengingat |
| upload / download | unggah / unduh |
| login / logout | masuk / keluar |
| password | kata sandi |
| user | pengguna |
| generate | buat, hasilkan |

Istilah yang sudah sangat umum dipakai pengguna produkmu (misalnya "login" di aplikasi anak muda) boleh dipertahankan. Yang penting konsisten: pilih satu, pakai di seluruh produk.

## Kata kabur yang perlu diganti fakta

| Kabur | Lebih jelas |
|---|---|
| segera | dalam 2 jam, paling lambat Jumat |
| beberapa waktu | 3 hari |
| berbagai fitur | sebut fiturnya, atau "4 fitur baru" |
| dan lain-lain | sebut semua, atau "misalnya A dan B" |
| secara berkala | setiap bulan |
| relatif murah | Rp15.000 per bulan |

## Kata yang terdengar besar tapi kosong

Hindari kecuali merujuk hal yang spesifik: sinergi, ekosistem, transformasi, akselerasi, holistik, komprehensif, inovatif, solusi terdepan, game changer.
